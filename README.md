# weather-reminder

* prepares you for the weather of the day
*  Fetch daily weather forecast from API
*  Parse data for chance of rain and temperatures below a certain number
*  Print statement to console
### Future plans
* Automated email alert every morning
### Tech stack
* Java/bash
* cron to run Java program every morning, jakarta for email
* plain text file (.txt) for log
* wttr.in for weather data using Java's httpclient
